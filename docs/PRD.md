# PRD: استوديو أوركست (Orchest Studio)

## 01 Product overview

| Field | Value |
| --- | --- |
| Product name | أوركست (Orchest Studio) |
| Tagline | المنصة الفاخرة للزفات الخليجية والشيلات وطلبات التنفيذ الصوتي |
| Description | منصة ويب متخصصة تعرض أعمال استوديو أوركست من زفات وشيلات وتتيح الاستماع المستمر والطلب المباشر والمخصص عبر واتساب. تخدم العملاء الباحثين عن بصمة صوتية لمناسباتهم وصاحب الاستوديو لإدارة الأعمال ومتابعة الإحصائيات بدقة. |
| Stage | MVP |
| Platform | Web app (Mobile-First, Responsive Desktop) |

## 02 Problem

اليوم، يضطر الزبون الذي يستعد لمناسبة زواج أو تخرج للبحث في قنوات يوتيوب مبعثرة أو محادثات واتساب وتلقي ملفات صوتية غير منظمة، مما يفقده القدرة على معاينة الخيارات وفهم أسعار وتفاصيل الإيقاعات، بينما يعاني صاحب الاستوديو من استقبال رسائل غير محددة تفتقر لاسم الزفة أو التفاصيل الأساسية للطلب.
هذا يكلف الزبون ضياعاً للوقت وتجربة استماع رديئة تنقطع مع كل خروج من الصفحة، ويكلف صاحب الاستوديو وقتاً طويلاً في الاستفسارات اليدوية وضياع زبائن محتملين لعدم وجود قمع تحويل مباشر.

## 03 Goal

مساعدة العملاء المقبلين على مناسبات في اختيار الزفة أو الشيلة وسماعها بدقة وتجهيز طلبهم المخصص بالأسماء والمناسبة للانتقال فوراً للواتساب خلال أقل من دقيقة وبدون أي تشتت أو انقطاع للصوت.

## 04 Target users

Primary user (الزبون النهائي):
- Who: العرسان، أهالي العروسين، ومنظمو الحفلات الباحثين عن زفات وشيلات خليجية راقية.
- Trigger: اقتراب موعد الزفاف أو المناسبة والرغبة في حجز وتخصيص عمل صوتي بأسماء العروسين.
- Today they use: البحث العشوائي في يوتيوب، إنستغرام، ورسائل واتساب اليدوية.
- They will switch because: تجربة استماع فاخرة بمشغل صوتي مستمر لا ينقطع، إمكانية الطلب بنقرة واحدة، ونافذة تخصص أسماءهم وبياناتهم بدقة قبل الانتقال للواتساب.

Secondary users:
- صاحب ومدير الاستوديو (Admin): يحتاج لوحة تحكم سريعة لرفع وإدارة الأعمال (صوتيات سحابية أو روابط يوتيوب)، تغيير رقم واتساب الطلبات مباشرة، تحليل أكثر الأعمال طلباً، وتصدير النسخ الاحتياطية.

Not for:
- منصات التوزيع والموسيقى العالمية (مثل Spotify أو Anghami) ذات الاشتراكات الشهرية وتراخيص البث الجماعي؛ المنصة مخصصة لبيع وتنفيذ أعمال صوتية مخصصة حسب الطلب.
- الشراء المباشر الفوري بالبطاقة البنكية دون تخصيص؛ كل عمل يعتمد على تنفيذ صوتي بشري ومراجعة من الاستوديو.

## 05 Core features

| # | Feature | What the user can do | Done when |
| --- | --- | --- | --- |
| 1 | المشغل الصوتي المستمر (Sticky Audio Player) | تشغيل أي زفة أو شيلة مع تصفح باقي أقسام الموقع واستمرار الصوت في شريط سفلي عائم بموجات تفاعلية | يستمر المقطع الصوتي دون توقف أو إعادة تشغيل عند الانتقال بين الصفحات أو فتح النوافذ المنبثقة |
| 2 | الطلب الذكي عبر واتساب (WhatsApp Checkout Funnel) | فتح نافذة "اطلب هذه الزفة باسمك"، إدخال أسماء العروسين وتاريخ المناسبة ونوع التعديل، والتحويل للواتساب | يتم فتح تطبيق واتساب برسالة منسقة وجاهزة تتضمن كود العمل واسمه وتفاصيل التعديل والأسماء ورابط العمل |
| 3 | البحث الدلالي الذكي والاقتراحات (AI Intent & Similar Tracks) | كتابة طلب بلغة طبيعية (مثلاً: "زفة هادية بدون موسيقى") وعرض نتائج مطابقة مع قسم للأعمال المشابهة تحت كل عمل | يعرض النظام نتائج مطابقة لنية المستخدم، وتظهر تلقائياً قائمة أعمال مشابهة أسفل صفحة كل عمل |
| 4 | تبديل الوضعين الداكن والفاتح (Dark/Light Mode) | التبديل الفوري بين المظهر الملكي الأسود والذهبي والمظهر الفاتح النظيف بنقرة زر واحدة | تتغير خلفيات وألوان البطاقات والنصوص فوراً مع حفظ التفضيل محلياً (localStorage) |
| 5 | إدارة الأعمال والوسائط المتعددة (Media Manager) | إضافة وتعديل الأعمال الصوتية برفع ملفات مباشرة (Cloud R2/S3) أو إضافة روابط يوتيوب مع تحديد نوع الإيقاع والتصنيف | يتم حفظ العمل ويظهر في الصفحة الرئيسية والتصنيف المخصص مع جاهزيته للتشغيل الفوري |
| 6 | التحكم برقم الواتساب والنسخ الاحتياطية (Admin Settings & Backup) | تعديل رقم الواتساب المعتمد للطلبات بضغطة زر، وتصدير قاعدة البيانات كـ JSON وسجل الطلبات كـ Excel/CSV | يتم تحديث وجهة روابط الطلب في الموقع فورياً بدون تعديل كود، ويتم تحميل ملف النسخة الاحتياطية بنجاح |
| 7 | لوحة التحليلات والإحصائيات (Analytics Dashboard) | معاينة معدل التحويل ونسب الاستماع، والأعمال الأكثر طلباً عبر واتساب، وسجل استفسارات العملاء | يظهر رسم بياني للأعمال الأكثر تفاعلاً وجدول تفصيلي يسجل كل نقرة تمت لطلب الواتساب |

Key user flow:
1. يفتح الزبون الموقع على الجوال أو المتصفح، ويبحث أو يفلتر حسب التصنيف (زفات عروس، بدون موسيقى، شيلات).
2. يضغط على زر التشغيل السريع فيستمع للمقطع عبر المشغل المستمر، ويتصفح تفاصيل العمل والأعمال المشابهة.
3. يضغط "اطلب هذه الزفة باسمك"، يدخل الأسماء ونوع التعديل، ثم يضغط زر الإرسال لينتقل للواتساب مع رسالة جاهزة ومعتمدة، بينما يسجل النظام عملية التحويل في لوحة التحكم.

## 06 Success metrics

| Metric | Target | Measured by |
| --- | --- | --- |
| نسبة التحويل للواتساب (Conversion Rate) | > 3.5% | (عدد النقرات على "إرسال للواتساب" ÷ إجمالي زيارات الموقع) من لوحة التحكم |
| زمن بقاء المستمع (Session Duration) | > 2.5 دقيقة | معدل مدة الاستماع الفعلي للزفات لكل زائر |
| اكتمال تفاصيل الطلب (Lead Data Accuracy) | 100% | استقبال صاحب الاستوديو لرسائل واتساب متضمنة كود العمل والأسماء ونوع التعديل تلقائياً |

## 07 Out of scope

- بوابات الدفع الإلكتروني المباشر (مثل Stripe أو بطاقات الائتمان)؛ الاعتماد كامل على التحويل للواتساب والاتفاق المالي المباشر.
- حسابات وتسجيل دخول للزبائن (User Auth للعميل)؛ الزائر يتصفح ويطلب كـ Guest دون الحاجة لإنشاء حساب أو كلمة مرور.
- تطبيق جوال أصيل (Native iOS/Android App)؛ يتم التركيز بالكامل على تطبيق ويب تقدمي متجاوب (Responsive Web App).
- محرر صوتيات أونلاين أو قص وتعديل الصوت من المتصفح للزبون.

## 08 Open questions

- هل يتم اعتماد Cloudflare R2 كخيار تخزين رئيسي للصوتيات لتفادي تكاليف الـ Bandwidth، أم البدء بتخزين Supabase Storage؟
- هل يُطلب إرسال إشعار فوري لصاحب الاستوديو (عبر بوت تيليجرام أو بريد إلكتروني) عند نقر أي عميل على زر طلب الواتساب كنسخة إضافية مع سجل لوحة التحكم؟
